The commands that change nothing on the machine exist in the Python `rnfmac`,
and settle its patterns: one subprocess seam (`Runner`), a `Layout` for `$HOME`
and `$RNF_HOME`, and findings reported through `rn-forge-commons` with the
shell's exit codes.
[Port plan, Phase 2](../../python-tool-port.md#phase-2-port-the-read-only-commands).

## S1.3.1 — subprocess seam, layout and findings report

**State:** Closed (2026-11-21)

**Acceptance:**

- `domain/runner.py` and `adapters/process.py` are the only place commands run
  subprocesses; tests substitute a fake runner.
- `domain/layout.py` resolves every path from `$HOME` and `$RNF_HOME`, so tests
  run against `tmp_path`.
- `domain/report.py` collects findings and maps them to the exit codes in
  `docs/guides/commands.md`.

## S1.3.2 — rnfmac doctor and system doctor

**State:** Closed (2026-11-21) · **Depends on:** S1.3.1

**Acceptance:**

- `rnfmac doctor` and `rnfmac system doctor` report the shell versions' findings
  with their exit codes; `system doctor` stays presence-only.
- `tests/test_doctor.py` and `tests/test_system_doctor.py` port the relevant
  shellspec examples.
