# S1.5.1 — bootstrap.sh

Brief for [S1.5.1](../F1.5-cutover.md#s151-bootstrapsh), at `7c39a57` on branch
`feature/python-tool-port`.

## Goal

Add a small, sourceable `bootstrap.sh` at the repository root that gets a fresh
Mac from nothing to an installed Python `rnfmac`: Homebrew, then uv, then
`rnfmac self install`. It replaces `shell/install.sh`, which S1.5.2 deletes.

## Settled

Lead (reviewer) decisions, 2026-11-22, under the owner's go-ahead for F1.5 (port
plan, Phase 4, step 1):

- **Location and shape:** `bootstrap.sh` at the repository root, `#!/bin/zsh`
  with `# shellcheck shell=bash`, bash-parseable (no zsh-only expansions). It
  does not source shkit and has no shdoc annotations; it logs with
  `printf 'bootstrap: %s\n' ... >&2`. Publishing it as a release asset and the
  README's bootstrap line are S1.5.2, not this story.
- **Sourced contract:** no `set -e`, no `exit`, anywhere in the file. All work
  happens in a function `rnfmac_bootstrap`, called at the bottom with `"$@"`;
  every helper function and every temporary variable it defines is `unset`
  after the call. On success it exports `PATH="${RNF_HOME}/bin:${PATH}"` in
  the caller's shell; on failure it prints `bootstrap: installation failed`
  and ends with `false`, so the sourcing shell sees a non-zero status and
  keeps running.
- **Arguments:** `--force` (reinstall Homebrew), `--archive <file>` and
  `--version <version>`. `--archive` and `--version` must come together,
  because `rnfmac self install --archive` requires `--version`. Anything else,
  a missing value, or one of the pair alone: print
  `bootstrap: usage: . bootstrap.sh [--force] [--archive <file> --version <version>]`
  and return 1 before running anything.
- **`RNF_HOME`:** `export RNF_HOME="${RNF_HOME:-${HOME}/.rn-forge}"` at the top
  level of the file (top level, not inside a function — CLAUDE.md invariant:
  assignments made in a function of a sourced file vanish under zsh).
- **Homebrew** (today's `setup_homebrew`, `shell/commands/system/init.sh:93`):
  the prefix is `"${HOMEBREW_PREFIX:-/opt/homebrew}"` — that variable is the
  test seam. If `<prefix>/bin/brew` exists and `--force` is not given, log
  that Homebrew is present and skip; otherwise run
  `/bin/bash -c "$(curl -fsSL --proto '=https' --tlsv1.2 https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`.
  Either way, activate it afterwards with
  `eval "$("<prefix>/bin/brew" shellenv)"`. A failed installer, or no
  `<prefix>/bin/brew` after it, returns 1.
- **uv:** if `command -v uv` finds nothing, `brew install uv`; a failure returns
  1\.
- **rnfmac:** without `--archive`,
  `uvx --from git+https://github.com/rn-forge/macsetup rnfmac self install`
  (the default branch's code; `self install` itself picks the latest release).
  With `--archive <file> --version <v>`,
  `uvx --from <file> rnfmac self install --archive <file> --version <v>`. A
  non-zero exit returns 1. A missing archive file returns 1 with
  `bootstrap: archive not found: <file>` before anything runs.
- **Next steps:** on success, print the two follow-ups, `rnfmac system init` and
  `rnfmac sync`, one line each.

## Current behaviour

There is no `bootstrap.sh`. `shell/install.sh` (whole file) installs shkit, then
the shell dist, then clones `config/`; Homebrew and uv are installed by
`shell/commands/system/init.sh:79` `setup_homebrew` and the Python
`rnfmac system init` installs neither
(`src/rn_forge/macsetup/services/system_init.py:122`). Each test below fails
before the change because `bootstrap.sh` does not exist (zsh: "no such file or
directory", non-zero status).

## Tests first

New `tests/test_bootstrap.py`. Each test runs
`subprocess.run(["zsh", "-f", "-c", script], env=..., capture_output=True, text=True)`
where `script` is
`. <repo>/bootstrap.sh <args>; print -r -- "rc=$?"; print -r -- "PATH=$PATH"; typeset -f rnfmac_bootstrap >/dev/null && print leaked`
(add `print alive` to prove the caller survived). The environment is minimal:
`HOME` and `RNF_HOME` from the autouse fixture, `HOMEBREW_PREFIX=<tmp>/brew`,
and `PATH=<tmp>/stubs:/usr/bin:/bin`, so no real `brew`, `uv` or `uvx` is
reachable. The stubs, written by a helper in the test file, append
`<name> <args>` to `<tmp>/calls.log` and exit 0 unless the test says otherwise:

- `<tmp>/stubs/curl`: prints a script that creates an executable
  `$HOMEBREW_PREFIX/bin/brew` stub (the same recorder).
- the `brew` stub: on `shellenv`, prints `export PATH="<prefix>/bin:$PATH"`;
  otherwise records and exits 0.
- `<tmp>/stubs/uvx`: records and exits 0 (or 1 where a test needs it).
- `<tmp>/stubs/uv`: present only in the test that says so.

Tests, each failing before the change as above:

- `test_installs_homebrew_uv_and_rnfmac`: no brew under the prefix; `rc=0`; the
  log is, in order, the curl of the Homebrew installer URL, `brew install uv`,
  then
  `uvx --from git+https://github.com/rn-forge/macsetup rnfmac self install`;
  `PATH` starts with `$RNF_HOME/bin`; output names `rnfmac system init` and
  `rnfmac sync`; no `leaked`.
- `test_skips_homebrew_when_present`: brew stub pre-created under the prefix;
  `rc=0`, no curl in the log.
- `test_force_reinstalls_homebrew`: brew present, `--force`; curl is in the log.
- `test_skips_uv_when_present`: a `uv` stub on `PATH`; no `brew install uv`.
- `test_archive_installs_from_the_file`: an existing file `<tmp>/m.tar.gz`,
  `--archive <tmp>/m.tar.gz --version 1.2.3`; the uvx line is
  `uvx --from <tmp>/m.tar.gz rnfmac self install --archive <tmp>/m.tar.gz --version 1.2.3`
  and no `git+` appears.
- `test_bad_arguments_print_usage` (parametrized: `--archive x` alone,
  `--version 1` alone, `--archive` with no value, `--bogus`): `rc=1`, the
  usage line on stderr, `alive` printed, an empty log.
- `test_missing_archive_fails_before_anything_runs`: `rc=1`,
  `archive not found`, an empty log.
- `test_a_failed_install_returns_without_exiting`: the uvx stub exits 1; `rc=1`,
  `bootstrap: installation failed`, `alive` printed, `PATH` does not start
  with `$RNF_HOME/bin`, no `leaked`.
- `test_has_no_set_e_or_exit`: no non-comment line of `bootstrap.sh` matches
  `\bset -e\b|\bexit\b`.
