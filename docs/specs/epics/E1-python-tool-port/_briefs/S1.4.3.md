# S1.4.3 — rnfmac brew sync

Brief for [S1.4.3](../F1.4-machine-changing-commands.md#s143-rnfmac-brew-sync),
at `143b1a6` (line references) on branch `feature/python-tool-port`.

## Goal

Port `shell/commands/brew/sync.sh` to `rnfmac brew sync`, and add the streaming
run that this and the later Phase 3 commands (relay, system sync and init) need:
their tools print progress the user must see live.

## Settled

- **`Runner.stream(args, *, cwd=None) -> int`** is added to the `Runner`
  protocol (`domain/runner.py`): runs with inherited stdin/stdout/stderr and
  returns the exit code, `NOT_FOUND` (127) when the command cannot be started.
  `SubprocessRunner` implements it with
  `subprocess.run(list(args), cwd=cwd, check=False)`; `FakeRunner`
  (`tests/support.py`) records the call in `calls` like `run` and returns the
  scripted result's `returncode` (unscripted non-git → 127). Lead (reviewer)
  decision, 2026-11-21, under the owner's go-ahead for Phase 3.
- **Brewfile:** `<config checkout>/hosts/<host>/Brewfile`, as the shell
  (`sync.sh:21`) — *not* the copy `profile sync` puts in the product home.
- **Failure:** the shell runs under `set -e`, so the first failing `brew`
  command ends it with that command's exit code. Keep that: raise
  `SystemExit(code)` after an `console.error` line naming the command.
- Messages: success "Brew packages synced successfully" after cleanup, then
  stream `brew list`, then success "Brew sync complete !".

## Current behaviour

`shell/commands/brew/sync.sh:25` `sync_packages`:
`brew bundle install --file=<Brewfile> --verbose --force`, then
`brew bundle cleanup --file=<Brewfile> --verbose --force`, success line,
`brew list`; then the closing success line. No existence check of the Brewfile
(brew reports it). Python today: `commands/brew.py` registers only `diff`;
`rnfmac brew sync` exits 2 "No such command 'sync'". `Runner` has only `run` and
`which`.

## Change

- **Change:** `domain/runner.py` (`stream` on the protocol),
  `adapters/process.py` (`SubprocessRunner.stream`), `tests/support.py`
  (`FakeRunner.stream`); new `services/brew_sync.py`; register `sync` on
  `brew_app` in `commands/brew.py`; add the command to
  `docs/guides/commands.md` beside the Python `brew diff` entry.
- **Leave alone:** `brew diff` and `services/brew_diff.py`.
