# Reference

Generated reference. Exact signatures come from doc comments, which the API
reference renders; how to use one entry point lives in that entry point's
`README.md`.

The shell product's per-function reference is generated by `mise run docs` from
`shdoc` annotations under `shell/` into `docs/reference/shell/`. It is
gitignored and is retired with the shell code in Phase 4 of the
[port plan](../specs/python-tool-port.md).
